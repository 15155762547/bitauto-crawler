# 飞书表结构约定

同步前需自行准备兼容的 Base。当前项目不提供从空白 Base 一键建完整库的命令。
表 ID 均通过环境配置；分类表按已配置 Base 中的英文或中英双语分类名称定位，歧义应停止。

| 表 | 关键字段 |
|---|---|
| 分站 | 分站代码、分站名称、来源入口、货币单位等 |
| 车系 | 车系唯一键、分站代码、来源车系ID、品牌/车系中英文名、销售状态、来源车系页 |
| 配置 | 款型唯一键、分站代码、来源车系ID、来源款型ID、车型全称、年款、中英文报价、货币代码 |
| 分类参数 | 款型唯一键、车型全称、分站名称、对应原文参数字段 |

稳定键示例是合成示意：`AE_12345`（配置），其中数字只代表该分站来源身份。
分类表保留官网英文参数字段和单位，名称转换规则见 `build_category_sheets.clean_field_name`。
同国家/同款型关系需按稳定身份写入，不按记录顺序关联。

封面用附件字段、图集用“图片URL JSON”文本字段。配置表的图集引用依赖车系表名称及
“分站代码/来源车系ID”字段，默认表达式引用 `vehicle_models`；若自建表改名，需调整表达式后验证。
来源暂停、未披露、失败和身份不符需保留真实状态，不能因展示精简改成已完成。

配置身份字段和用于建立链接的 ID 使用来源原值；不要把数组字段、select、文本或公式混写。
具体模块对其他可选字段的依赖见逐文件索引和对应预览输出。先在自己的测试 Base 小样验证，
再执行写入或维护。不得直接复用别人的 ID 或凭据。
