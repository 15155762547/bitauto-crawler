# 数据处理流程

```text
分站定义 → client（缓存/访问暂停）→ Pydantic 校验 → 同站双语归并
                                              ├→ 本地核查与证据
                                              └→ 飞书车系/配置与分类参数表
来源车系页面 → 图集分类/身份校验 → URL JSON → 预览/同步/回读
```

稳定身份按分站代码、来源车系 ID 和款型 ID 建立；不按名称、行号或动力类型猜测身份。
中文/英文缺一侧时保留披露差异，数字比较需要单位及测试标准，标配/选配等限定不能被清洗。
资料不足和待公布不等于参数错误，车系级图片也不能证明某款配置的专属外观。

`pipeline.py` 协调现有目标表的增量写入，本地核查用稳定键 upsert 并保留人工处理信息。
`build_category_sheets.py` 等维护模块处理分类字段或展示，不等于日常采集程序。
主表中的摘要文本与分类表参数目前可能独立保存，不能宣称全部为自动 lookup；
图集 JSON、封面等引用需要在用户自己的 Base 中按字段约定配置和验证。

本仓库只发布源码和离线测试，不包含历史生产响应或已完成采集的证据包。
测试通过说明对应规则和模拟接口行为通过，不意味着当前网站可访问、数据完整或已部署定时任务。
